# 🚚 CHOWRA Logistics & Couriers

A modern, responsive logistics and courier service website developed as part of a technical assessment for **SAC Info Tech Solutions**.

The website demonstrates a professional logistics landing page with shipment tracking, service information, network coverage, corporate logistics solutions, and an interactive rate calculator.

## 📌 Project Overview

CHOWRA Logistics & Couriers is a sample logistics website designed to provide customers with a clear and professional way to explore courier and logistics services.

The project focuses on:

* Modern UI/UX
* Responsive design
* Interactive components
* Shipment tracking experience
* Logistics service presentation
* Quick quote calculation
* Corporate logistics solutions
* Clean and maintainable component structure

> **Note:** This is a technical-assignment demonstration. Shipment information, customer testimonials, contact details, and other business information shown in the application are sample/demo content.

## ✨ Features

### 🏠 Professional Homepage

* Responsive navigation
* Modern hero section
* Logistics-focused visual design
* Clear call-to-action buttons
* Smooth section navigation

### 📦 Shipment Tracking

Users can enter a shipment/tracking ID and view a sample shipment status.

Example demo tracking ID:

```text
CHW123456789
```

The tracking interface demonstrates:

* Shipment status
* Current shipment location
* Delivery progress
* Shipment timeline
* Tracking events

### 🚚 Logistics Services

The website presents multiple logistics services:

* Domestic & International Courier
* Express Delivery
* E-commerce Logistics
* Freight & Cargo Services
* Pickup & Door-to-Door Delivery
* Corporate Logistics Solutions

### 💰 Rate Calculator

Users can enter shipment information and receive an estimated delivery quote.

Inputs include:

* Pickup location
* Destination
* Package type
* Package weight
* Service level

The calculator provides a sample estimated price based on the selected options.

### 🌍 Network Coverage

A visual representation of logistics network coverage with major service locations and routes.

### 🏢 Corporate Logistics

Dedicated information for businesses requiring:

* Bulk shipments

* E-commerce fulfillment
* Business logistics support

The application is designed to work across:

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Chandu-challa/CHOWRA-LOGISTICS-COURIERS.git
```

### 2. Navigate to the project

```bash
cd CHOWRA-LOGISTICS-COURIERS
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in browser

```text
http://localhost:3000
```

---

## 🏗️ Production Build

To create a production build:

```bash
npm run build
```

To start the production server:

```bash
npm start
```
